# Imprint for Claude Cowork

Imprint learns how you work from your decisions and briefs your agents so they act the way you would. This repository is the Claude plugin marketplace for Imprint's Cowork plugin.

You don't need to do anything here. Install the Imprint app from [imprintsystems.ai](https://imprintsystems.ai) and its setup adds this plugin to Claude for you.

The plugin talks only to the Imprint app on your own computer.
